# 风格增强 ML 指南

本文整理“风格增强 + 机器学习”路线的方法论。核心目标不是让 ML 在全市场里自动寻找所有风格，而是先人为定义清楚要承担的风格暴露，再让 ML 在受控股票池内部做排序增强。

## 一、为什么要从全市场 ML 转向风格增强

最初的直觉往往是：

```text
挖很多因子
+ 低相关组合
+ 丢给 GBDT / CatBoost / LightGBM
= 得到稳定超额收益
```

实际落地后会发现，这条路远比想象复杂。模型不只是在学 alpha，它还可能同时学到：

- 小市值暴露；
- 高波动暴露；
- 动量暴露；
- 行业暴露；
- beta 暴露；
- 某段行情里的偶然规律；
- 数据和标签里的时序偏差。

这样会导致一个问题：模型回测好时，不知道收益来自哪里；模型回测差时，也不知道是因子失效、风格切换、交易逻辑、风控，还是数据问题。

因此，更可控的路线是：

```text
先定义我要承担什么风格风险
再在这个风格内部寻找 alpha
最后用 ML 做轻量增强
```

也就是：

```text
风格池
-> 排雷过滤
-> 透明排序基线
-> ML 排序增强
-> 风格暴露和风险监控
```

## 二、中证 500 本身也是一种风格

中证 500 不是全市场中性池。它本身已经带有明显风格暴露：

- 中盘 / 中小盘；
- 非超大盘龙头；
- 行业混合；
- 成长、周期、价值、防守混杂；
- 波动通常高于沪深 300；
- 对市场风险偏好比较敏感。

所以“中证 500 增强”本质上也是风格增强，只是它是一个比较粗的风格池。它的问题是内部风格太混杂，模型容易在不同时期学到不同风格，导致样本外漂移。

更细的风格池，例如“红利低波”“小市值质量”“趋势动量”，任务更窄，更容易归因。

## 三、风格增强的基本框架

### 1. 风格池

风格池回答：

```text
我到底要赚哪种风格的钱？
```

例如红利低波：

```text
高股息
低波动
现金流较稳定
估值不过热
流动性达标
```

例如小市值质量：

```text
市值偏小
但不是垃圾股
流动性达标
波动不过高
质量不差
```

这一步不是为了找最强个股，而是为了确定策略身份。

### 2. 排雷过滤

排雷过滤回答：

```text
哪些股票虽然属于这个风格，但明显不该买？
```

红利低波里的排雷例子：

- 高股息但现金流差；
- 高股息但盈利连续恶化；
- 高股息但负债高；
- 高股息来自股价暴跌；
- 趋势明显破位；
- 成交异常低迷。

小市值质量里的排雷例子：

- 亏损严重；
- 现金流恶化；
- 财务质量差；
- 高波动暴雷特征；
- 流动性不足；
- 近期极端下跌。

排雷因子不一定有很高 ICIR。它们的价值可能体现在减少左尾、降低最大回撤、减少踩雷概率。

### 3. 透明排序基线

在引入 ML 之前，应先有一个不用 ML 的透明排序基线。

例如红利低波：

```text
score =
  分红可持续性 rank
+ 现金流质量 rank
+ 估值安全 rank
+ 盈利稳定 rank
+ 趋势确认 rank
- 下行风险 rank
```

例如小市值质量：

```text
score =
  小市值暴露 rank
+ 盈利质量 rank
+ 现金流质量 rank
+ 中期动量 rank
- 波动风险 rank
- 财务风险 rank
```

透明基线的意义是：先验证这个风格和规则本身是否站得住。ML 必须证明它比透明基线有增益。

### 4. ML 排序增强

ML 不负责决定策略身份，也不负责无限制选股。

ML 的任务是：

```text
在已经定义好的风格池和排雷过滤之后，
对剩余股票做池内排序增强。
```

也就是说：

```text
风格池决定能不能买
排雷规则决定哪些不能碰
透明基线提供可解释排序
ML 只做增厚收益的排序器
```

这能显著降低 ML 的复杂度。

## 四、ML 因子应该怎么选

不能盲目把所有因子都丢进去，也不能只因为因子“符合故事”就硬塞给模型。

更合理的是分三类候选。

### 1. 风格结构因子

这些因子帮助模型理解风格内部结构。

红利低波例子：

- 股息率；
- 波动率；
- 下行波动；
- 分红稳定性；
- 现金流质量；
- 估值安全；
- 盈利稳定；
- 趋势是否破位。

注意：这些因子在风格池内部的单调 ICIR 可能不高。因为它们的主要作用可能已经在“建池”阶段被使用掉了。

是否进入 ML，不能只看故事，要看是否有：

- 非线性结构；
- 条件交互价值；
- 尾部排雷能力；
- 加入模型后的样本外增益。

### 2. 排雷因子

这些因子主要用于识别坏样本。

例如：

- 高负债；
- 现金流恶化；
- 盈利下滑；
- 成交恶化；
- 趋势破位；
- 股息率异常高但质量差。

排雷因子不一定提升平均 IC，但可能降低最大回撤和极端亏损。

### 3. 通用 alpha 因子

可以加入少量非风格专属的通用 alpha 因子，例如：

- 中期动量；
- 短期反转；
- 成交活跃度变化；
- 行业相对强弱；
- 估值修复；
- 盈利改善。

但通用 alpha 因子不能改变策略身份。最终持仓仍必须来自风格池，并满足风格暴露约束。

## 五、单因子 ICIR 不高是否就不能用

从第一性原理看，如果一个因子在目标样本空间里对未来收益的条件分布没有任何信息，那么加入 GBDT 只会增加噪音和过拟合风险。

但“单调 ICIR 不高”不等于“完全没用”。可能存在几种情况：

### 1. 非线性有用

例如股息率不是越高越好：

```text
太低不好
中高较好
异常高可能是红利陷阱
```

单调 IC 可能不高，但分桶后可能有结构。

### 2. 交互有用

例如：

```text
高股息 + 高现金流质量 = 可能好
高股息 + 现金流差 = 可能是陷阱
```

单独看股息率或现金流质量，ICIR 都可能一般，但组合有价值。

### 3. 尾部排雷有用

因子可能不擅长排序全部股票，但擅长识别最差的一批股票。这类因子要看左尾风险和最大回撤，而不是只看 ICIR。

### 4. 状态依赖有用

某些因子只在市场下跌、风格逆风、流动性变差时有效。全样本 ICIR 会稀释它们的价值。

因此，对 ML 因子的准入应使用更完整的标准：

- 单因子 Rank IC；
- 分层收益；
- 非线性分桶；
- 条件交互；
- 加入模型后的样本外增益；
- 样本外特征重要性；
- 对最大回撤和左尾的改善；
- 对持仓风格漂移的影响。

如果一个因子满足：

```text
单因子 IC 低
分桶无结构
交互无逻辑
加入模型 OOS 无改善
特征重要性不稳定
```

那就不应该进入模型，即使它听起来很符合风格故事。

## 六、如何避免风格漂移

风格增强的核心不是禁止所有非风格因子，而是要有边界。

可以允许通用 alpha 因子参与池内排序，但最终组合必须满足：

- 股票来自目标风格池；
- 股息率 / 市值 / 波动 / 质量等核心暴露仍然达标；
- 行业集中度不过高；
- beta 不失控；
- 波动和回撤不偏离策略定位；
- 通用 alpha 因子不能主导成另一个策略。

对于 GBDT / CatBoost / LightGBM，换因子可能导致模型结构大变。因为树模型不是简单线性权重，而是学习条件分裂。新增或删除因子可能改变整棵树的结构，导致持仓风格大幅变化。

因此因子更新要谨慎：

- 不要频繁大换因子；
- 新因子先进入候选或观察；
- 对比旧模型和新模型的预测相关性；
- 对比持仓重合率；
- 检查行业、市值、波动、红利等暴露；
- 检查样本外收益和最大回撤是否真的改善。

## 七、如何避免前视偏差

风格池不能用未来数据静态回填历史。正确做法是生成动态 membership：

```text
date, instrument, in_style_pool
```

任意交易日只能使用当时已经可见的信息。

### 半年调池方案

可以参考指数编制，每半年调一次风格池：

```text
2010-12 调整池子 -> 用于 2011-01 ~ 2011-06
2011-06 调整池子 -> 用于 2011-07 ~ 2011-12
```

调池时点只能使用调池日前已经知道的数据：

- 调池日前价格；
- 调池日前成交量；
- 调池日前已公告财务数据；
- 调池日前已公告分红数据；
- 调池日前 ST / 停牌 / 上市状态。

不能使用：

- 调池后价格；
- 调池后才公告的财报；
- 调池后才发生的分红；
- 调池后半年内收益表现。

如果财务公告日期不可靠，第一版可以选择：

- 少用财务数据；
- 或对财务数据加保守滞后；
- 或先使用价格、成交量、波动率、流动性等更容易控制时序的字段。

训练和回测必须使用同一套动态风格池逻辑：

```text
训练样本按当时风格池过滤
预测样本按当时风格池过滤
交易只能买入当时风格池内股票
```

## 八、红利低波与小市值质量是否互补

红利低波和小市值质量可以形成一定互补，但不是严格对冲。

红利低波偏防守：

- 高股息；
- 低波动；
- 稳定现金流；
- 低估值；
- 风险偏好下降时可能更抗跌。

小市值质量偏进攻：

- 中小盘弹性；
- 风险偏好；
- 市场活跃度；
- 资金扩散；
- 牛市或结构性行情中可能更有弹性。

二者组合更像：

```text
一个负责稳
一个负责攻
```

而不是：

```text
一个跌，另一个一定涨
```

它们仍然都是股票多头，系统性下跌时可能同时下跌，只是受伤方式和幅度可能不同。

第一版可以简单做：

```text
5 只红利低波增强
+ 5 只小市值质量增强
= 总持仓 10 只
```

先验证：

- 两个风格池收益相关性；
- 两个风格策略收益相关性；
- 回撤是否错开；
- 50/50 组合是否降低最大回撤；
- 收益是否被明显稀释；
- 2022、2024 等困难年份谁更抗跌。

## 九、推荐落地顺序

不要一上来就做完整动态 ML 系统。推荐顺序如下。

### 第一步：构建风格池

先做红利低波、小市值质量两个半年调池版本。

先验证风格池自身：

- 等权收益；
- 相对中证 500 收益；
- 波动；
- 最大回撤；
- 行业暴露；
- 市值暴露；
- 年度表现。

### 第二步：加入排雷规则

验证排雷前后：

- 最大回撤是否下降；
- 最差月份是否改善；
- 左尾收益是否改善；
- 收益是否被明显牺牲。

### 第三步：建立透明排序基线

不用 ML，先用少量可解释 rank 因子做排序。

验证：

- Top 组是否优于等权；
- Top-bottom 是否稳定；
- 是否降低回撤；
- 是否保持风格暴露。

### 第四步：ML 轻量增强

在前三步基础上，再加入 GBDT / CatBoost / LightGBM。

ML 必须和透明基线对比：

- Rank IC；
- Top10 收益；
- 年化收益；
- 最大回撤；
- 换手率；
- 持仓重合率；
- 预测相关性；
- 风格暴露是否漂移。

如果 ML 没有稳定提升，就不要强行使用。

### 第五步：组合两个风格

先固定配比，例如：

```text
50% 红利低波增强
50% 小市值质量增强
```

或者持股数量上：

```text
5 只红利低波
5 只小市值质量
```

不要一开始动态配权。先确认两个风格是否真的互补。

## 十、核心原则

1. ML 不应负责所有事情。
2. 风格池先决定策略身份。
3. 排雷规则先处理明显风险。
4. 透明基线先证明不用 ML 也能站住。
5. ML 只做池内排序增强。
6. 因子不能只看故事，也不能只看单调 ICIR。
7. 风格相关因子必须证明有边际信息，否则不进模型。
8. 通用 alpha 因子可以用，但不能让组合跑偏。
9. 风格池、训练、预测、交易必须使用同一套无前视逻辑。
10. 最终验证对象不是单因子，而是组合。

一句话总结：

```text
先把要赚的钱定义清楚，再让模型帮忙多赚一点。
不要让模型自己决定你到底在赚什么钱。
```
