# 机器学习量化交易每日课程

这里存放每天可以直接使用的掌握学习课程。

学习方式很简单：

1. 先打开当天的 Markdown 文档。
2. 只学当天写明的 1 到 3 个小概念。
3. 做完“你来试试”和“掌握检查”。
4. 3 分制自评达到 3 分，再进入下一天。
5. 如果没有达到 3 分，回到当天的“如果还没掌握”。这不是失败，只是说明这个概念还值得再看一遍。

每天不需要新建一个 Jupyter Notebook。Notebook 按主题组织：

```text
trade_tutorial/notebooks/
  01_features_and_labels.ipynb  # 对应 Day 1-14
```

第 1 周主要是概念、手算和小表格。需要代码时，把练习追加到对应 Notebook 的当天小节里。
