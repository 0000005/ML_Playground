# Day 6：第一周掌握检查

## 今天只做一件事

检查第 1 周的核心概念是否真的掌握。

今天不急着学新东西。掌握学习里，检查不是考试，而是帮你发现哪里还值得再拆小。

## 你已经学过

这一周你已经学过：

- 因子就是特征。
- 未来收益就是标签。
- 样本是一行可学习的数据。
- 模型可以先理解成自动学习权重的打分器。
- 回归、分类、排序是三种不同任务。

## 10 分钟复盘

把本周内容压缩成一条线：

```text
某天某只股票的因子
-> 变成机器学习特征 X
-> 未来收益或未来分组
-> 变成标签 y
-> 很多行样本组成训练数据
-> 模型学习 X 和 y 的关系
-> 用模型预测新日期股票
-> 按预测值排序并调仓
```

如果这条线能说顺，第 1 周的骨架就搭起来了。

### 练习 2：判断任务类型

判断下面任务是回归、分类还是排序：

1. 预测未来 20 日收益率。
2. 判断股票是否进入未来收益前 30%。
3. 每月选预测分数最高的 50 只股票。
4. 预测未来是否跑赢行业平均。
5. 按模型分数分成 5 组看收益。

### 练习 3：小表格

构造一张至少 6 行的小表，字段包括：

```text
date
code
pe
momentum_20d
future_return_5d
```

指出哪些列是特征，哪一列是标签。

建议把这张表写入 `trade_tutorial/notebooks/01_features_and_labels.ipynb` 的 Day 6 小节。
