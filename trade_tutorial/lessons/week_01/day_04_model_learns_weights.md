# Day 4：模型就是自动学权重的方法

## 今天只学一件事

机器学习模型可以先理解成：自动学习如何组合特征的打分器。

## 你已经知道

你已经知道多因子策略可以手工加权：

```text
score = 0.5 * 动量 + 0.5 * 质量
```

这个公式里，`0.5` 和 `0.5` 是你手工给的权重。

## 10 分钟讲解

机器学习做的第一件事，可以先想得很朴素：

```text
让历史数据告诉我们，哪些特征应该更重要。
```

比如线性模型可能学到：

```text
pred = 0.3 * 动量 + 0.1 * ROE - 0.2 * 波动率
```

这里的 `0.3`、`0.1`、`-0.2` 就是模型从历史样本中学到的权重。

你不需要今天就理解怎么求出这些权重。今天只要先掌握：

```text
手工多因子：人来设定权重
机器学习模型：模型从历史样本中学习权重或规则
```

模型不是魔法。它只是试图从历史样本中找出特征和标签之间的关系。

## 一个小例子

假设你有两个特征：

- 20 日动量
- ROE

你手工打分可能写：

```text
score = 0.5 * momentum_20d + 0.5 * roe
```

机器学习模型可能通过历史数据发现：

```text
score = 0.7 * momentum_20d + 0.3 * roe
```

这不代表模型一定对。它只是基于历史数据学到了一个组合方式。后面还必须用样本外数据和回测验证。

## 如果还没掌握

先把模型想成一个会调旋钮的人。

每个因子都有一个旋钮：

```text
动量旋钮调高一点
估值旋钮调低一点
波动率旋钮可能变成负的
```

模型训练就是根据历史样本调这些旋钮。调完以后，还要检查它在未来样本上是否真的有用。
